# Stopwatch & Timer

A precise stopwatch with lap times, plus a countdown timer with alert — right in your browser. No signup, no server.

**Live:** <https://stopwatch.slippylabs.com/>

## What it does

- A stopwatch with lap times, accurate to the hundredth of a second.
- A countdown timer with 1/5/10/25-minute presets and an alert when it hits zero.

## Run it locally

A static site. No build step, no package manager, no dependencies:

```
git clone git@github.com:slippylabs/stopwatch.slippylabs.com.git
cd stopwatch.slippylabs.com
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
